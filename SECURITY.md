# Security / Сообщение об уязвимостях

Supported version: **3.0.x**. This program runs as root and changes IP forwarding rules. Restrict client source networks, protect every gateway management port and keep independent console access when changing routing.

For a sensitive report, use the repository's **Security → Report a vulnerability** form: [private report](https://github.com/mrPortnov/proto-cascade/security/advisories/new). Include the version, expected/actual behavior and a minimal example with documentation addresses. Keep credentials, private keys, live configurations and personal data out of reports and public issues. Ordinary reproducible usage problems can be reported in [Issues](https://github.com/mrPortnov/proto-cascade/issues).

Поддерживаемая версия: **3.0.x**. Программа работает с root-правами и меняет правила переадресации. Ограничивайте сеть клиентов, защищайте все порты управления шлюзом и сохраняйте доступ к консоли при изменении маршрутизации.

Для чувствительного сообщения используйте **Security → Report a vulnerability** по ссылке выше. Укажите версию, ожидаемое/фактическое поведение и минимальный пример с демонстрационными адресами. Не прикладывайте пароли, токены, приватные ключи, рабочие конфигурации и персональные данные. Обычные воспроизводимые проблемы эксплуатации можно описать в Issues.
